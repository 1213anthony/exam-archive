# 기출문제 아카이브 검색 사이트

배포: https://1213anthony.github.io/exam-archive/  (예전 2D 화면: `/classic/`)

## 화면 (2026-09 3D로 재구축)
- **3D 은하**: 분류 12개가 행성으로 떠 있다(크기 = 시험 수). 클릭하면 카메라가 날아
  들어가 과목이 유리 카드 격자로 펼쳐지고, 카드를 누르면 오른쪽 패널에 시험 목록.
  검색하면 해당 행성·카드만 점등. 즐겨찾기한 과목은 은하 화면에 위성으로 떠 있다.
  단축키: `/` 검색, `Enter` 첫 결과로 비행, `Esc` 한 단계 나가기, `Tab`으로 행성·카드 이동.
- **목록 모드**: 우상단 `목록` 토글. 예전과 같은 2D 리스트. 폰·저사양·"움직임 줄이기"
  설정에서는 자동으로 이 모드가 켜진다.
- 시험 한 줄 = **문제 한 장 + 해설 한 장**. 같은 시험지가 A4/B4로 여러 벌이면 용량이
  큰 것 하나만 보여준다. 한쪽이 없으면 "해설 없음"으로 표시.
- **정리 필요만**: 문제지나 해설 한쪽이 안 보이는 시험만(현재 19개).
- 즐겨찾기·접힘 상태는 브라우저(localStorage)에만 저장된다. 키 이름은 예전 화면과 같다.

## 프론트 개발 (`web/`)
```
cd web
npm install
npm run dev        # http://localhost:5173/exam-archive/  (루트의 data.js를 그대로 읽는다)
npm test           # 실제 data.js 기준 회귀: 시험 1877 / 과목 102 / 정리 필요 19 / 연도 미상 0
npm run build      # 결과가 리포 루트(index.html, assets/)에 써진다 → git push 하면 배포
```
- 데이터 가공 로직은 `web/src/lib/archive.ts` 한 곳에 있다. 시험 키·중복 합치기·
  세부과목 나누기(2학년/3학년은 절대 안 합침)·정렬·정리 필요 기준. 바꾸면 테스트가 잡는다.
- `data.js`는 번들에 넣지 않고 런타임에 읽는다. **크롤링만 다시 돌리고 push 하면**
  프론트를 다시 빌드하지 않아도 갱신된다.
- 배포 방식은 그대로(main 브랜치 루트 = GitHub Pages). 빌드 결과를 커밋한다.

## 관리 모드 (파일을 드라이브 휴지통으로)
우하단 자물쇠 → Google 로그인. `web/.env`에 아래를 넣고 빌드해야 켜진다:
```
VITE_GOOGLE_CLIENT_ID=...     # OAuth 클라이언트(유형: 웹), 승인된 원본에 https://1213anthony.github.io
VITE_ALLOWED_ADMINS=me@sshs.hs.kr
```
- 완전 삭제는 없다. 휴지통 이동만 하고 화면의 기록에서 되돌릴 수 있다.
- 파일마다 `canTrash`를 먼저 확인해서, 권한 없는 파일은 × 가 비활성화되고 소유자 이메일이
  뜬다. 아카이브 파일 대부분은 학생 계정(예: 24031@sshs.hs.kr) 소유라 그 계정으로
  로그인해야 실제로 지워진다.

## 구조
- **분류(12개)** → **과목** → **시험(연도·학기·중간/기말)** 3단계
- 시험 한 줄에 [문제] 버튼과 [해설] 버튼이 나란히 놓임 — 둘을 따로 찾을 필요 없음
- 한쪽이 없으면 "해설 없음"처럼 회색으로 표시돼서, 빠진 자료가 뭔지 바로 보임
- 검색창은 분류/과목/연도/파일명 전부를 대상으로 필터링
- 우측 "정리 필요만" 버튼: 폴더 분류가 잘못됐거나 파일명 규칙이 안 맞는 항목만 추려서 보기

그래서 첫 크롤링 결과 527개는 물리 자료만 센 숫자임.

`crawl.py`의 ROOT_FOLDER_ID를 상위 폴더(`1_W8bDBPF5zGU3B9JuAt5g2Ycsjq7VpkH`)로
이미 바꿔놨음. 이 폴더에 12개 분류가 전부 들어있음:
국어 / 수학 / 물리 / 화학 / 생명과학 / 지구과학 / 정보 / 사회 / 외국어 / 실험 / 예체능 / 창의융합특강

**crawl.py를 한 번 더 실행하면 전체가 수집됨.** (이미 인증은 끝났으니 이번엔
브라우저 로그인 없이 바로 돌아감 — token.json이 저장돼 있어서.)

## crawl.py 실행 방법
```
pip install google-auth-oauthlib google-api-python-client
```
1. https://console.cloud.google.com 에서 새 프로젝트 생성
2. "API 및 서비스" → "라이브러리"에서 Google Drive API 활성화
3. "사용자 인증 정보" → "OAuth 클라이언트 ID 만들기" → 애플리케이션 유형: **데스크톱 앱**
4. 다운로드한 JSON을 `credentials.json`이라는 이름으로 이 폴더에 저장
5. `python crawl.py` 실행 → 브라우저가 열리면 학교 계정으로 로그인 → 읽기 권한 승인
6. 완료되면 `data.json`, `data.js`가 전체 데이터로 교체됨

## 실제로 확인된 것 (정직하게 남겨둠)
- 파일명 규칙이 **같은 과목 안에서도, 심지어 같은 폴더 안에서도** 다름. 확인된 것만 3가지:
  1. `01_문제지_(고급물리학1)_2021년1중간(B4).pdf`
  2. `문제지_양자역학_2025년_1기말(B4).pdf`
  3. `2024_2기말_고급물리학I_문제지.pdf` (괄호 없음, 순서도 다름)
  세 패턴 다 파서에 반영함. 앞으로 또 다른 변형이 나올 가능성 있음 — 그럴 땐
  `parsed_ok: false`로 걸러지니 데이터 손실 없이 fallback으로 넘어감.
- **완전히 똑같은 이름의 폴더가 중복 생성된 사례를 실제로 발견함**: "고급물리학1 →
  1학기 중간고사" 밑에 "고급물리학1"이라는 폴더가 2개 있음. 이게 바로 처음에 말했던
  "인수인계 때마다 파일이 새로 생기는" 문제의 실물 증거임. `crawl.py`는 이제 이런
  형제 폴더 이름 중복을 자동 감지해서 `duplicate_sibling_folder: true`로 표시함
  — 이 필드로 정리(병합/삭제)할 후보를 바로 걸러낼 수 있음.
- 2011~2014년 자료는 규칙이 거의 없음 (예: `일반물리학1문제지201101중간.pdf`처럼 구분자 없이
  붙어있거나, 연도 자체가 파일명에 없는 것도 있음). 이런 파일은 `parsed_ok: false`로
  표시되고, 사이트에서 "미분류" 태그가 붙음 — 검색은 되지만 연도/학기 필터에는 안 걸릴 수 있음.
- **폴더명 자체가 틀린 경우도 있었음**: "2학기 중간고사" 폴더 안에 1학기 파일이 섞여 있는 등.
  이런 파일은 "폴더 불일치" 태그로 표시됨 — 인수인계 과정에서 잘못 옮겨진 파일을 찾는
  용도로도 그대로 쓸 수 있음.
- 물리학1 폴더의 `문제지_물리1_2012년_1중간.pdf`는 파일 크기가 4KB로 비정상적으로 작음
  (다른 문제지는 보통 200KB~3MB). 깨졌거나 빈 파일일 가능성이 있어서 확인 추천.
